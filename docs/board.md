# 트랙 보드

계획과 실측에서 렌더된다. 보드는 아무것도 쓰지 않는다.

## 로컬 서버

```bash
track serve                      # 기본 127.0.0.1:4747
track serve --host 0.0.0.0       # 다른 기기에서 볼 때만
```

SSE 로 실시간 갱신한다. 2초마다 트랙 문서 변경을 보고, 90초마다 또는 요청 시 프로브를 다시 잰다.

**기본이 루프백인 이유** — 보드에는 프로브 결과, 레포명, 브랜치명이 그대로 실린다.
카페나 사무실 Wi-Fi 에서 열려 있을 이유가 없다. 다른 기기에서 볼 때만 명시적으로 연다.

## 화면

| 영역 | 무엇 |
|---|---|
| 환경 레인 | `env` 별로 스텝을 늘어놓는다. 게이트 체인이 가로로 보인다 |
| 결정 레인 | `rests-on` 이 가리키는 결정. SUPERSEDED 되면 스텝이 `낡음` 으로 뜬다 |
| 세션 그래프 | 어느 세션이 어느 스텝을 들고 있고 서로 무엇을 주고받았나 |

세션 그래프는 문서화되지 않은 Claude Code 내부 구조(`~/.claude/sessions/`, 트랜스크립트)를
읽어 만든다. 버전이 바뀌면 조용히 깨질 수 있고, 일부 세션 파일은 필드가 없어 건너뛴다.

## 서버 없이 보기 — 스냅샷 보드

```bash
track board                          # ./track-board.html
track --track <id> board --out <경로>
```

상태를 인라인한 자기완결 HTML 하나가 나온다. 서버도 포트도 데몬도 없고, 그대로 Artifact 로
올리면 폰에서도 열린다. 같은 file_path 로 다시 게시하면 URL 이 유지된다.

UI 는 로컬 서버판과 **같은 파일 한 벌**이다. `window.__TRACK_STATE__` 가 심겨 있으면 정적
모드로 떨어져 서버를 부르지 않고, 실측·트랙 전환·그래프 모드 버튼은 잠긴다. 상단 표시가
`스냅샷 · <시각>` 으로 바뀐다.

**경로는 걷어낸다.** 스냅샷에 실리는 상태에서 로컬 절대경로는 홈을 `~` 로 줄이고, 문서 경로는
파일명만 남기고, 세션의 `cwd` 는 아예 뺀다. 레포명·브랜치명은 남는다 — 그게 보드의 내용이다.

**한계.** 만든 시점의 사진이다. 자동 갱신이 없으므로 다시 보려면 `track board` 를 다시 돌린다.
실시간이 필요하면 로컬 서버를 쓴다.
